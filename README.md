# ICT Smart Money Trade Journal

Dark-themed ICT (Inner Circle Trader) education dashboard built with **React + Vite + Tailwind CSS**.

## Run locally
```bash
npm install
npm run dev
```
Then open the URL printed in the terminal (typically `http://localhost:5173`).

## Production build (also used by Vercel)
```bash
npm run build
npm run preview
```
Open the URL printed for preview (typically `http://localhost:4173`).

## Deploy to Vercel
- Import this repo on Vercel
- Build command: `npm run build`
- Output directory: `dist`
